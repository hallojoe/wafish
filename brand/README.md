# Wafish identity

The mark combines a W with three incoming paths and a central routing junction.
`mark.svg` is the editable master. Keep its proportions and clear space.

Run `npm --prefix website run assets` to produce all exports.
The root `logo.png`, README cover, social image, and website downloads use this master.
The administration icon uses the same paths with its current text color.

Use graphite `#141915`, warm white `#f1f0e8`, and signal green `#d5f36b`.
Reserve orange `#ec956f` for warnings and rejected requests.
Use the monochrome mark when color is unavailable. Keep clear space equal to one branch width.
Use at least 24 pixels for the detailed mark. Favicons simplify the surrounding space.
Do not rotate, stretch, outline, or add effects to the logo.

Space Grotesk is the display face. IBM Plex Sans and IBM Plex Mono support body text and technical labels.
Font licenses are distributed with the website's brand download.
The project logo and original graphics follow the repository's MIT license.
