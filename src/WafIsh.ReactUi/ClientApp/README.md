# WafIsh React UI

See [setup, hosting, and verification](../../../docs/react-ui.md).

```bash
npm ci
npm run dev
npm test
npm run lint
npm run build
npm run test:e2e
```

Production assets are embedded in the .NET package.
The shadcn components and CSS are checked in under `src/components/ui`.
Their MIT license is included there. The shadcn CLI is not a runtime dependency.
